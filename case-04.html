Ultimate USB

1本の128GB USBメモリを、「PCレスキュー」「ポータブル開発環境」「暗号化保管庫」の3役に。構成のすべてをPowerShellで自動化・冪等化したプロジェクトです。

概要

起動しなくなったPCの救出(PCレスキュー)、どのPCでも同じ環境で開発できるポータブル開発環境、機密データを安全に持ち運ぶ暗号化保管庫。この3つの用途を1本のUSBメモリに同居させるプロジェクトです。Ventoy・PortableApps・VeraCryptを基盤に、構成全体をPowerShellスクリプトで管理しています。

何度実行しても同じ状態になる、セットアップエンジン

中心となるSetup-UltimateUSB.ps1は、catalog.jsonに定義したツール一覧を読み込み、未取得のものだけをダウンロードして配置します。レジューム対応のダウンロード、サイズ照合、7-Zip書庫の整合性テスト、バージョン更新チェック、プロキシ環境への対応まで組み込みました。

設計のポイント途中で中断しても、再実行するだけで正しい状態に収束する「冪等性」を最優先に設計しています。

どのPCでも、同じ開発環境を

VS Code・Git・WinPython・Arduino IDEなどをレジストリに依存しない形でポータブル化し、USBを挿すだけでどのWindows PCでも同じ開発環境を使えるようにしました。

さらに、pipのホイールやVS Code拡張機能(.vsix)、ドキュメント(Zeal)を事前に取得するNew-OfflineDevCache.ps1を実装。医療情報学向けに pydicom / SimpleITK / nibabel / fhir.resources を含む開発セットを、完全オフラインの環境でも構築できます。

PCレスキューと暗号化保管庫

感染が疑われるPCに挿した際にUSB自身を検査するInvoke-UsbSelfCheck.ps1(autorun.inf・.lnkワーム・隠し属性・二重拡張子・ハッシュ台帳の差分などを確認)、BitLockerで暗号化されたドライブの回復キー退避・アンロック・一時停止を行うInvoke-BitLocker.ps1を実装しました。

現場作業を同意書・作業ログ・証跡つきで記録して報告書を自動生成する案件管理(New-Case.ps1)や、出動前にツール・ISO・空き容量を点検してGO/NO-GOを判定するTest-KitReadiness.ps1も用意しています。

  • catalog.json駆動の冪等セットアップ(レジューム対応DL・書庫検証・更新チェック)
  • VS Code / Git / Python / Arduino IDE のポータブル開発環境
  • 感染PC診断用のUSB自己検査(ワーム・隠し属性・ハッシュ台帳差分など)
  • BitLocker回復キー退避・案件管理・出動前点検(GO/NO-GO判定)
