QuakeScope — Earthquake Alarm

Solo projectESP32 · Browser

Computes a JMA-style seismic intensity from the shaking where it sits, sounds an alarm and notifies your phone — my Arduino prototype rebuilt into something you can assemble and use.

I rebuilt my Arduino Uno prototype around a single ESP32. The detection engine is portable C++ that runs both on the device and in the browser via WebAssembly. JMA’s intensity filter is fitted to a 100 Hz IIR cascade so intensity updates while the ground is still shaking; P waves are caught early, while door slams, footsteps and sensor noise are ignored. Setup happens from a phone, and alerts go to LINE, Telegram, Discord and email. A 3D-printed case, board layout, bill of materials and assembly guide are included.

  • JMA’s intensity filter fitted to a 5-section IIR cascade; the “0.3-second value” tracked with a 30-entry min-heap, so intensity updates mid-quake (max diff 0.072 over 96 synthetic quakes)

  • The same C++ runs on the device and as WebAssembly, so anyone can try sample quakes or a phone’s accelerometer in the browser; the case is parametric and can be regenerated

Tremor measurement × DSP

TremorScope

Solo projectWindows (WPF / .NET 10) + ESP32Web edition uses the phone’s sensor

Measures hand tremor with an accelerometer and compares rest vs. posture numerically — a measurement aid for clinics.

Signals from a self-built sensor (ESP32 + MPU6050) on the back of the hand arrive via Azure IoT Hub; rest and postural tremor are each recorded for 20 seconds. Peak frequency, amplitude, estimated displacement and regularity come from a Welch spectrum, and results go into a printable report or to a PACS as DICOM. A simulated sensor lets anyone try it without hardware.

QuantScope

Solo projectWindows (WPF / .NET 10) + WebFor research & learning

Count and measure nuclei and particles in microscopy images, by stacking processing steps into a reusable “recipe”.

A ground-up rebuild of an image-processing app from a class assignment, now an analysis tool for research and learning. Stack 31 operations (blur → threshold → morphology…) and measure area, shape and intensity per particle. For IHC, colour deconvolution separates the stains and the positive rate comes from DAB per nucleus. All image processing and measurement is hand-written, and the same core runs in the browser via WebAssembly.
