MyDicomViewer

Solo projectWindows (WPF / .NET 10) + Webv1.0.0 released

A DICOM viewer and cloud PACS with a pneumonia-screening AI that runs entirely on the PC.

A viewer that feels like clinical reading software, with on-device pneumonia screening (EfficientNet-B0 on ONNX Runtime) and Grad-CAM explanations. CASE 03 — EMBEDDED × IoT

Earthquake Alert System

Solo projectArduino Uno + ESP-01S

The moment it detects shaking, your phone gets a push notification — a self-built earthquake alert device.

Raw 3-axis accelerometer readings are calibrated to compute shake magnitude, shown as a live waveform on an OLED. Two alert levels change the buzzer’s rhythm and pitch, so the danger level is clear without looking at a screen.

  1. Real-time shake magnitude with zero-offset and sensitivity calibration
  2. Buzzer, LED and OLED output change with the alert level
  3. Push notifications to a phone via ESP-01S and the Telegram Bot API

CASE 04 — SYSADMIN × AUTOMATION

Ultimate USB

Solo projectWindows (PowerShell)

PowerShell-driven configuration that turns one USB drive into a PC rescue kit, dev environment and encrypted vault.

On top of Ventoy, PortableApps and VeraCrypt, a setup engine fetches and places every tool defined in catalog.json. It is idempotent: if interrupted, simply re-run it and it converges to the correct state.

  1. Idempotent setup with resumable downloads, archive verification and update checks
  2. The same VS Code / Git / Python / Arduino IDE environment on any PC
  3. Self-check for infected PCs, BitLocker recovery-key handling, auto-generated work reports

CASE 05 — TEAM HACKATHON × BIOSIGNAL

AI-SHOW (Aishō)

Team projectTeam leadWeb (Next.js + FastAPI)Serverless web edition

Estimates heart rate and stress from a video interview, so both sides can share their nerves and talk more openly.

Built at a hackathon with team “Life & Medical Hackers”. As team lead I handled ideation, frontend, backend, the pitch deck and the presentation. It is not a lie detector: the core idea is sharing nervousness with consent.

  1. Contactless heart rate, HRV and stress from face video via rPPG (POS method)
  2. Privacy by design: no video stored, only consented numbers are shared
  3. AI voice-interview and human modes, plus auto-generated post-interview reports
  4. After the event, I ported the signal processing and interview logic to JavaScript and published a serverless web edition that runs on phones — verified to match the Python version on identical inputs

MEASUREMENT AID
CASE 07 — DESKTOP × IoT × SIGNAL PROCESSING

TremorScope

Solo projectWindows (WPF / .NET 10) + ESP32Web edition uses the phone’s sensor

Measures hand tremor with an accelerometer and compares rest vs. posture numerically — a measurement aid for clinics.

Signals from a self-built sensor (ESP32 + MPU6050) on the back of the hand arrive via Azure IoT Hub; rest and postural tremor are each recorded for 20 seconds. Peak frequency, amplitude, estimated displacement and regularity come from a Welch spectrum, and results go into a printable report or to a PACS as DICOM. A simulated sensor lets anyone try it without hardware.

IMAGE ANALYSIS
CASE 09 — IMAGE ANALYSIS × WEB

QuantScope

Solo projectWindows (WPF / .NET 10) + WebFor research & learning

Count and measure nuclei and particles in microscopy images, by stacking processing steps into a reusable “recipe”.

A ground-up rebuild of an image-processing app from a class assignment, now an analysis tool for research and learning. Stack 31 operations (blur → threshold → morphology…) and measure area, shape and intensity per particle. For IHC, colour deconvolution separates the stains and the positive rate comes from DAB per nucleus. All image processing and measurement is hand-written, and the same core runs in the browser via WebAssembly.
