CASE 02 — HARDWARE × GAME

Abbild

個人開発Windows (C# / MonoGame) + Arduinoブラウザーでも遊べる

心拍・振り・傾き・息で戦う。自作コントローラーで体を使って遊ぶ、100階層のダンジョンRPG。

WinFormsで作った脈拍センサー連動のRPGを、C#とMonoGameで一から作り直しました。Arduinoの自作コントローラー(脈波・加速度・湿度センサー)で読み取った体の動きが、20種類のミニゲームの入力になります。キーボードやゲームパッドでも同じように遊べるよう体の入力を1つの形にまとめ、ルールは画面から切り離してテストしています。

CASE 03 — EMBEDDED × IoT

地震即時アラートシステム

個人開発Arduino Uno + ESP-01S

揺れを検知した瞬間、スマートフォンに通知が届く。地震アラート装置を一式自作。

3軸加速度センサーの生値をキャリブレーションで補正して揺れの大きさを算出し、OLEDに波形履歴を表示。揺れに応じた2段階の警戒レベルでブザーの間隔と音程を変え、画面を見なくても危険度が伝わるようにしました。

  1. ゼロ点オフセットと感度のキャリブレーションによる、揺れ量のリアルタイム算出
  2. 警戒レベルに応じて、ブザー・LED・OLED表示を切り替え
  3. ESP-01SからTelegram Bot APIを経由して、スマートフォンへプッシュ通知

CASE 05 — TEAM HACKATHON × BIOSIGNAL

AI-SHOW（相性）

チーム開発リーダーWeb (Next.js + FastAPI)サーバー不要のWeb版

Web面接の映像から心拍・ストレスを推定し、互いの緊張を共有して率直な対話を後押しするサービス。

ハッカソンにチーム「Life & Medical Hackers」で参加し、リーダーとして企画・フロントエンド・バックエンド・発表資料・プレゼンまでを担当。嘘を見抜くツールではなく、緊張を「同意のうえで共有する」ことを設計の軸にしました。

  1. 顔映像からrPPG(POS法)で脈波を抽出し、心拍数・HRV・ストレスを非接触で推定
  2. 映像は保存せず、同意した数値のみを共有するプライバシー設計
  3. AI音声面接/人対人面接の両モードと、面接後のレポート・ES照合サマリー自動生成
  4. 大会後、信号処理と面接ロジックをJavaScriptに移植し、サーバー不要でスマホからも使えるWeb版を公開(Python版と同じ入力で結果が一致することを確認)

CASE 07 — DESKTOP × IoT × SIGNAL PROCESSING

TremorScope

個人開発Windows (WPF / .NET 10) + ESP32スマホのセンサーで測れるWeb版

手のふるえを加速度センサーで測り、安静時と姿勢時を数値で比べる、医療機関向けの測定補助ソフト。

手の甲に付けた自作センサー(ESP32 + MPU6050)の信号をAzure IoT Hub経由で受け取り、安静時と姿勢時を20秒ずつ記録します。Welch法のスペクトルからピーク周波数・大きさ・推定変位・規則性を求め、診察の記録に貼れるレポートやDICOMとしてPACSへ送れます。センサーがなくても、模擬センサーで一通り試せます。

VolumeScope

個人開発Windows (WPF / .NET 10) + ブラウザー版v1.0.0 公開

CTのDICOMから3断面と3Dを並べて表示し、計測や3Dプリント用のSTL書き出しまでできるCT 3Dワークステーション。

CTのシリーズを位置情報から正しく3D化し、横断・冠状断・矢状断のMPRと、ボリュームレンダリング・面・MIPを表示します。マーチングキューブス法による穴のない面の生成と、CPUだけで動くレイキャスティングを自作しました。人工の胸部CT(見本の模型)が入っているので、データがなくても試せます。

CASE 09 — IMAGE ANALYSIS × WEB

QuantScope

個人開発Windows (WPF / .NET 10) + ブラウザー版研究・学習用

顕微鏡の画像から、細胞の核や粒子を数えて測る。手順を「レシピ」として積み重ねる画像解析アプリ。

授業で作った画像処理アプリを、研究・学習用の解析ツールとして作り直しました。ぼかし→二値化→形を整える、と31種類の処理を積み重ね、粒ごとの面積・形・明るさを計測します。免疫染色は染色を分けて(カラーデコンボリューション)核ごとのDABの量から陽性率を出します。画像処理と計測はすべて自作で、同じ計算の部品をWebAssemblyにしたブラウザー版も公開しています。

  2. Lambert–Beerの法則にもとづく染色の分離と、粒ごとの値の分布に大津の方法をかけた陽性しきい値
